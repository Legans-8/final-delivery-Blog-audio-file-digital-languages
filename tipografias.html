Práctica de las propiedades tipográficas de CSS.

> font-family
Ejercicio 1#ff-serif
font-family: Georgia, serif;

Fuente con serifas. Remates en los extremos de cada trazo. Clásica, editorial, formal.

Amazing Fantasy

Ejercicio 2#ff-sans
font-family: Arial, sans-serif;

Sin serifas. Trazo limpio y uniforme. Moderno, legible en pantalla, neutro.

Amazing Fantasy

Ejercicio 3#ff-mono
font-family: "Courier New", monospace;

Monoespaciada. Cada carácter ocupa el mismo ancho. Ideal para código y estética retro.

Amazing Fantasy

> font-size
Ejercicio 4#fs-px
font-size: 32px;

Píxeles. Tamaño fijo absoluto. No escala con preferencias del usuario ni el contenedor.

¡THWIP!

Ejercicio 5#fs-rem
font-size: 2.5rem;

Relativo al tamaño raíz (html). Escala con preferencias del sistema. Más accesible.

¡THWIP!

Ejercicio 6#fs-em
font-size: 1.8em;

Relativo al tamaño del elemento padre. Se acumula en elementos anidados.

¡THWIP!

Ejercicio 7#fs-clamp
font-size: clamp(1rem, 4vw, 2.5rem);

Tipografía fluida. Mínimo, valor ideal y máximo. Se adapta al ancho del viewport.

¡THWIP!

> font-weight
Ejercicio 8#fw-100
font-weight: 100;

Thin / Hairline. El trazo más delgado posible. Elegante, frágil, ligero.

SPIDER

Ejercicio 9#fw-400
font-weight: 400;

Normal / Regular. El peso estándar de lectura. Valor por defecto del navegador.

SPIDER

Ejercicio 10#fw-700
font-weight: 700;

Bold. Negrita estándar. Énfasis, títulos, llamadas a la acción.

SPIDER

Ejercicio 11#fw-900
font-weight: 900;

Black / Heavy. El trazo más grueso. Impactante, héroe, portada de cómic.

SPIDER

> font-style & font-variant
Ejercicio 12#fst-italic
font-style: italic;

Cursiva. Inclinación tipográfica para énfasis, diálogos o pensamientos internos.

"...con un gran poder
viene una gran responsabilidad."

Ejercicio 13#fst-oblique
font-style: oblique 20deg;

Oblicua. Inclinación artificial del trazo normal, sin usar la versión italic del tipo.

"...con un gran poder
viene una gran responsabilidad."

Ejercicio 14#fv-smallcaps
font-variant: small-caps;

Versalitas. Las minúsculas se muestran como mayúsculas reducidas. Estilo editorial.

Miles Morales

> text-align
Ejercicio 15#ta-left
text-align: left;

Alineado a la izquierda. Lectura natural en idiomas LTR. Valor por defecto.

Ejercicio 16#ta-center
text-align: center;

Centrado. Ideal para títulos, poemas, portadas y elementos decorativos.

¡Tu amigable vecino arácnido está aquí para salvar el día! No importa el peligro.

Ejercicio 17#ta-right
text-align: right;

Alineado a la derecha. Útil para precios, fechas, firmas o textos RTL.

¡Tu amigable vecino arácnido está aquí para salvar el día! No importa el peligro.

Ejercicio 18#ta-justify
text-align: justify;

Justificado. Ambos márgenes alineados. Ajusta el espaciado entre palabras.

¡Tu amigable vecino arácnido está aquí para salvar el día! No importa el peligro.

> text-decoration
Ejercicio 19#td-underline
text-decoration: underline;

Subrayado. Línea bajo el texto. Se usa en links o énfasis tipográfico.

Peter Parker

Ejercicio 20#td-overline
text-decoration: overline;

Línea sobre el texto. Poco común; útil para anotaciones o elementos especiales.

Peter Parker

Ejercicio 21#td-through
text-decoration: line-through;

Tachado. Línea a través del texto. Indica eliminación, precio anterior o ironía.

Peter Parker

> text-transform
Ejercicio 22#tt-upper
text-transform: uppercase;

Todo en mayúsculas. El HTML puede estar en minúsculas; CSS lo transforma visualmente.

amazing fantasy

Ejercicio 23#tt-lower
text-transform: lowercase;

Todo en minúsculas. Convierte incluso mayúsculas del HTML a lowercase.

AMAZING FANTASY

Ejercicio 24#tt-cap
text-transform: capitalize;

Primera letra de cada palabra en mayúscula. Útil para nombres y títulos.

the amazing spider-man

> letter-spacing & word-spacing
Ejercicio 25#ls-tight
letter-spacing: -0.05em;

Tracking negativo. Las letras se acercan. Usado en títulos grandes para densidad visual.

SPIDER-MAN

Ejercicio 26#ls-wide
letter-spacing: 0.3em;

Tracking positivo. Las letras se separan. Elegante en caps, logotipos y subtítulos.

SPIDER-MAN

Ejercicio 27#ws-wide
word-spacing: 1.5em;

Separación entre palabras. Distinto al letter-spacing: afecta solo los espacios.

Into The Spider Verse

> line-height & text-shadow
Ejercicio 28#lh-tight
line-height: 1;

Interlineado ajustado. Las líneas se tocan o superponen. Impacto visual en títulos.

Con un gran poder
viene una gran
responsabilidad.

Ejercicio 29#ts-comic
text-shadow:
3px 3px 0 #ff0000,
6px 6px 0 #0000ff;

Sombras múltiples apiladas. Sin desenfoque. Efecto risograph / impresión cómic.

Spider-Man
