<title> Texto en la pestaña del navegador y en resultados de búsqueda. ALL
<link rel="stylesheet"> Vincula una hoja de estilos CSS externa. Se apilan: global.css + css específico de página. ALL
<script src=""> Vincula JavaScript externo. Al final del <body> para no bloquear el renderizado. IDX
<body> Contenedor de todo el contenido visible de la página. ALL

// Box Model y espaciado
PropiedadDescripciónArchivo
margin Espacio exterior del elemento. Shorthand: top right bottom left. Separa cajas entre sí. ALL
padding Espacio interior. Entre borde y contenido. Afecta el tamaño si no hay box-sizing. ALL
border Borde del elemento. Shorthand: grosor estilo color. Base del estilo manga-box (3px solid #000). ALL
width / height Dimensiones del elemento. Acepta px, %, vw/vh, auto. ALL
max-width Límite máximo de ancho. Wrapper limitado a 1000px centrado con margin: 0 auto. ALL
min-height Altura mínima garantizada aunque el contenido sea menor. Paneles de demo en TY y FB. TY FB
overflow: hidden Recorta el contenido que desborda el contenedor. Banners e imágenes con object-fit. ALL
box-shadow Sombra de caja: X Y blur spread color. Efecto manga offset: 5px 5px 0px #000. ALL
position: relative / absolute / fixed / sticky Tipo de posicionamiento. Controla el flujo normal del documento y el stacking context. ALL
top / left / z-index Coordenadas de posicionamiento y capa de apilamiento. Mayor z-index = por encima. IDX TY
// Tipografía
PropiedadDescripciónArchivo
font-family Fuente tipográfica. Base del sitio: "Courier New" monospace. Lista de fallbacks. ALL
font-size Tamaño de texto. Acepta px, rem, em, %, vw, clamp(). Clave para la jerarquía visual. ALL
font-weight Grosor del trazo tipográfico. 100 (thin) a 900 (black). bold = 700, normal = 400. ALL
font-style Estilo: normal, italic, oblique [grados]. Cursiva o inclinación artificial. TY
font-variant Variante tipográfica. small-caps: minúsculas como mayúsculas reducidas. TY
text-align Alineación horizontal del texto: left, center, right, justify. ALL
text-decoration Decoración: underline, overline, line-through, none. Links usan none. ALL
text-transform Transformación: uppercase, lowercase, capitalize. No modifica el HTML, solo la vista. ALL
letter-spacing Espaciado entre letras (tracking). Negativo = denso, positivo = aireado. Acepta em. ALL
word-spacing Espaciado entre palabras. Solo afecta los espacios, no las letras individuales. TY
line-height Interlineado. Unitless (1.5) = múltiplo del font-size actual. Afecta la legibilidad. ALL
text-shadow Sombra de texto: X Y blur color. Apilado sin blur = efecto risograph / cómic. TY
text-underline-offset Distancia del subrayado al texto base. Complementa text-decoration: underline. TY
white-space Control de saltos de línea: nowrap evita quiebre, pre conserva espacios. TY
// Flexbox
PropiedadDescripciónArchivo
display: flex Activa el modelo de caja flexible. Los ítems se alinean en un eje. ALL
flex-direction Eje principal: row (→ default), row-reverse, column (↓), column-reverse. ALL
justify-content Distribución en el eje principal: flex-start, center, flex-end, space-between, space-around, space-evenly. ALL
align-items Alineación en el eje transversal: flex-start, center, flex-end, stretch, baseline. ALL

flex-wrap Permite el salto de línea de ítems: nowrap (default), wrap, wrap-reverse. ALL

flex-shrink: 0 El ítem no se comprime aunque no haya espacio. Útil para imágenes y badges fijos. FB TY
gap Espaciado entre ítems flex o celdas grid. Reemplaza márgenes entre elementos hijos. ALL
// CSS Grid
PropiedadDescripciónArchivo
display: grid Activa el modelo de cuadrícula bidimensional. Filas y columnas simultáneas. GD IDX
grid-template-columns Define las columnas del grid. Acepta px, fr, %, auto, repeat(), minmax(). GD IDX
grid-template-areas Nombra visualmente las áreas del layout con strings ASCII. Dashboard (EJ.4). GD
grid-area Asigna un elemento a un área nombrada con grid-template-areas. GD
grid-column: 1 / -1 El elemento abarca desde la primera hasta la última línea del grid (span completo). GD
repeat(auto-fit, minmax()) Grid responsivo sin media queries. El número de columnas se ajusta automáticamente. GD
fr (unidad) Fracción del espacio disponible. repeat(3, 1fr) = tres columnas iguales. GD
align-items (en grid) Alineación vertical de ítems dentro de sus celdas. center los centra verticalmente. GD

// Unidades y funciones
Unidad / FunciónDescripciónArchivo
px Píxeles. Unidad absoluta. No escala con preferencias de accesibilidad del usuario. ALL
rem Relativo al font-size del elemento raíz (html). Por defecto 1rem = 16px. Escalable. ALL
em Relativo al font-size del elemento padre. Se acumula en elementos anidados. ALL
% (porcentaje) Porcentaje del elemento padre. Fluid para anchos de columnas y posicionamiento. ALL
vw / vh 1% del ancho / alto del viewport. Tipografía fluida basada en pantalla. TY
fr Fracción del espacio disponible en grid. 1fr 1fr = dos columnas iguales. GD
clamp(min, ideal, max) Valor que escala entre mínimo y máximo. Tipografía fluida sin media queries. TY
minmax(min, max) Rango de tamaño en grid. minmax(220px, 1fr) = columna flexible con mínimo. GD
repeat(n, valor) Repite una definición N veces en grid. repeat(3, 1fr) = 3 fracciones iguales. GD

// Selección y manipulación del DOM
Método / PropiedadDescripciónArchivo
document.getElementById() Selecciona el elemento con ese id. Más directo que querySelector para ids únicos. IDX
document.querySelector() Selecciona el primer elemento que coincide con un selector CSS. IDX
document.querySelectorAll() Retorna un NodeList con todos los elementos que coinciden. Carátulas de álbumes. IDX
document.createElement() Crea un nuevo nodo HTML en memoria. Construye el div de cada mensaje del guestbook. IDX
element.innerHTML Lee o escribe el HTML interno de un elemento. Incluye etiquetas HTML en la cadena. IDX
element.innerText Lee o escribe solo el texto visible, sin interpretar HTML. Puntuación del snake. IDX
element.style.propiedad Modifica estilos inline desde JavaScript. Color del botón play/stop del reproductor. IDX
element.classList.add() Agrega una clase CSS al elemento sin reemplazar las clases existentes. IDX
element.appendChild() Agrega un nodo hijo al final del elemento. Inyecta mensajes en el guestbook. IDX
element.scrollTop Posición actual del scroll vertical. Se iguala a scrollHeight para ir al fondo. IDX
element.scrollHeight Altura total del contenido scrollable incluyendo lo no visible en pantalla. IDX
element.value Valor actual de un input o textarea. Se lee para obtener y se vacía para limpiar. IDX
element.focus() Mueve el foco del teclado al elemento. Devuelve el cursor al campo de texto. IDX
// Eventos
Evento / MétodoDescripciónArchivo
addEventListener(tipo, fn) Registra una función callback para escuchar un tipo de evento en el elemento. IDX
"DOMContentLoaded" Se dispara cuando el HTML está completamente parseado, sin esperar imágenes. IDX
"keydown" Se dispara al presionar una tecla. Captura flechas y espacio para controlar Snake. IDX
"submit" Se dispara al enviar un formulario. Captura el guestbook para procesarlo con JS. IDX
"mouseenter" / "mouseleave" Entrada y salida del cursor sobre un elemento. Tooltip de carátulas de álbumes. IDX
"mousemove" Movimiento continuo del cursor. Actualiza la posición del tooltip siguiendo al ratón. IDX
event.preventDefault() Cancela el comportamiento por defecto: recarga en submit, scroll en teclas de flecha. IDX
event.keyCode Código numérico de la tecla. 37=← 38=↑ 39=→ 40=↓ 32=espacio. IDX
event.pageX / pageY Posición del cursor relativa a la página completa. Posiciona el tooltip en hover. IDX
// Canvas 2D API — Snake.exe
